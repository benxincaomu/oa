# OA 办公自动化系统

## 📋 项目概述
这是一款基于 Spring Boot 3 构建的现代化企业级办公自动化系统，原生集成 Camunda BPM 工作流引擎，支持多租户架构和动态表单能力。系统提供完整的OA核心功能，包括身份与权限管理、组织架构管理、工作流设计与执行、动态数据建模等能力，可快速适配各类企业办公场景需求。

## ✨ 核心功能

### 🔐 身份与访问管理
- **用户管理**: 完整的用户增删改查、用户启用/禁用、密码重置、角色分配、部门分配、个人资料管理功能
- **角色与权限系统**: 树形权限模型、角色权限分配、基于角色的访问控制（RBAC）、前端菜单权限管理
- **认证与安全**: 无状态Token认证、Redis支撑的会话存储、请求授权安全过滤器、加盐密码加密
- **多租户支持**: 内置租户数据隔离、租户管理、租户维度的资源访问控制
- **系统初始化**: 首次运行自动初始化默认租户、超级管理员用户、默认角色、权限和组织架构
- **通知服务**: 集成邮件能力，支持密码设置、工作流通知、系统告警等场景

### 🏢 组织架构管理
- **部门结构**: 层级化部门管理、部门负责人配置
- **用户-部门映射**: 灵活的用户部门分配，支持用户归属多个部门
- **组织数据隔离**: 租户维度的组织架构管理

### 🚦 工作流管理（Camunda BPM 驱动）
- **工作流设计**: 可视化BPMN流程设计工作台、工作流定义管理、版本控制
- **工作流发布**: 设计完成的流程一键发布到Camunda引擎，自动部署相关资源
- **动态表单系统**: 自定义表单设计，支持动态实体定义、多种字段类型、表单校验
- **工作流执行**: 运行时流程实例管理、任务分配、审批流处理、自动任务路由
- **工作流历史**: 完整的流程执行历史追踪、审批记录、审计日志
- **数据表管理**: 动态生成表单数据存储表，支持不同工作流类型的自定义数据结构

## 📦 部署要求
- **JDK版本**: 21+
- **PostgreSQL版本**: 13+
- **Redis版本**: 6+
- **MinIO**: （可选，用于文件存储）
- **内存要求**: 最低2GB RAM，推荐4GB+
- **磁盘要求**: 最低10GB可用空间

## 🚀 快速开始指南

### 1. 环境准备
```bash
# 安装 JDK 21
# 安装并启动 PostgreSQL 数据库
# 安装并启动 Redis 缓存
# （可选）安装并启动 MinIO 对象存储
```

### 2. 数据库配置
```sql
CREATE DATABASE oa;
CREATE USER oa_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE oa TO oa_user;
```

### 3. 修改配置文件
编辑 `src/main/resources/application.yml` 配置文件，填入你的数据库、Redis和MinIO连接信息：
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/oa
    username: oa_user
    password: your_password
  data:
    redis:
      host: localhost
      port: 6379
  # MinIO 配置（如果使用文件存储功能）
  minio:
    endpoint: http://localhost:9000
    access-key: your_access_key
    secret-key: your_secret_key
```

### 4. 构建与运行
```bash
# 构建项目
./mvnw clean package

# 运行应用
java -jar target/oa-java.jar
```

### 5. 访问系统
- 首次运行系统会自动初始化默认管理员账号
- 默认登录凭据：`admin / admin123`（首次登录后请立即修改密码）
- API 访问地址：`http://localhost:8080`
- 监控端点：`http://localhost:8080/actuator`

## 🌟 项目亮点

### 🔧 低代码工作流能力
内置Camunda BPM引擎与可视化流程设计器，业务人员无需编码即可设计和发布审批流程，新流程需求开发周期缩短80%。

### 🎨 动态表单系统
灵活的动态实体定义系统，无需修改数据库Schema即可创建自定义数据结构和表单，完美适配各类业务场景和需求变化。

### 🔒 企业级安全保障
多层安全架构，包括无状态Token认证、RBAC权限控制、加盐密码加密、租户数据隔离，满足企业安全合规要求。

### 📈 可扩展架构
模块化设计，层级边界清晰，可根据业务增长轻松扩展新模块（考勤管理、文档管理、会议室预订等）。

### 📊 内置审计能力
完整的工作流历史追踪和操作日志，满足企业对流程透明化和责任追溯的审计要求。
